# Everyday_Cart
# Mini E-Commerce Product & Cart

## Description
A simple mini e-commerce web application built using React.  
It demonstrates clean component design, proper state management, filtering, sorting and cart functionality.

## Features
- Product listing using FakeStore API
- Search by product name
- Filter by category
- Sort by price (Low → High, High → Low)
- Add to cart / remove from cart
- Update item quantity with stock validation
- Cart summary (total items & total price)
- Persistent cart using localStorage
- Clean UI with responsive layout

## Tech Stack
- React
- Vite
- CSS
